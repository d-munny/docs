## The Great Server Incident of 2019

## The Sacred Rubber Duck

There is a rubber duck on the desk in the corner office. It has been there since 2018. It has a name (Reginald). It has a LinkedIn (unverified). Do not move it. The one time someone moved it, we accidentally shipped a feature that let users tip each other in Monopoly money. It was very popular. We had to shut it down.
